Catches K-code up with T3 Code 0.1.11 (about 4,300 upstream commits since K-code 0.1.9), shows when Oh My Pi compacts a conversation, and keeps K-code's instructions in place after it does.

## Highlights

- **Issues.** Browse and filter issues from GitHub, GitLab, Azure DevOps, Forgejo and Linear on a new Issues page (web and mobile), link them to threads, and let agents read and update them.
- **Durable workflows** on web and mobile, with questions that wait for you under **Needs you**.
- **Projects that span several repositories**, and worktree layout commands that run only after you approve them.
- **Oh My Pi compaction is visible.** When Oh My Pi compacts a long conversation on its own, the thread shows **Compacting context** while it runs and **Context compacted** when it is done, instead of looking stalled.

## New (from T3 Code)

- Preview tabs for another machine's localhost ports, on desktop and mobile.
- Link several machines at once, and read a linked machine's threads from this one.
- Agents can read, update and merge pull requests, read failing CI logs, and land a stack through MCP tools.
- The whole app is translated into every supported language.
- Themes with custom CSS and background images; agents can restyle the app.
- The computer stays awake while agents work.
- Dictation keeps recording into its thread when you switch away; Apple Speech on macOS.
- Keyboard shortcuts can be unassigned, and new ones cycle between terminals.
- Many fixes and speedups across the server, providers, terminals, diffs and mobile.

## K-code features

- Oh My Pi `ask` forms show checkboxes as **Yes / No** instead of `true / false`.
- The Claude account's plan (for example Max 20x) appears in Oh My Pi usage, read from Oh My Pi 19.

## Fixes

- After Oh My Pi compacts a conversation, the next message resends K-code's instructions (K-code tools, pull request linking, runtime notes), which were lost before.

## Breaking or migration notes

- The server's database moves the Web Push migration after T3 Code's new ones (to 117). Databases from 0.1.9 are repaired on first start; no action needed.
- Version numbers now follow the T3 Code release K-code is built on, so this release is 0.1.11 and there is no 0.1.10.
- Update the desktop app and the server together.
