Catches K-code up with T3 Code (about 330 upstream commits), adds account switching and an auto-compaction switch for Oh My Pi, and fixes a timeout when adding an environment behind Cloudflare Access.

## Highlights

- **Switch the Oh My Pi account from the thread.** Thread details shows the email of the account serving the thread under Usage limits. Hover it and pick another account; while the agent is working, the switch waits for the next turn, like `omp`'s own `/session pin`.
- **Auto-compaction switch for Oh My Pi** in **Settings → Providers → Oh My Pi**. Off stops Oh My Pi compacting a conversation on its own, whatever its own config says.
- **No more "timed out after 10000ms" behind Cloudflare Access.** The request clock now waits for the Access sign-in, so a slow sign-in no longer fails a healthy server.

## New (from T3 Code)

- **Kiro** as a provider.
- **Copy thread** copies a link that opens the thread, on web, desktop and mobile.
- Provider status banners get a **Refresh** button.
- The model picker lists the Claude models Claude Code reports.
- Electron 44.10.1 with the October Chromium security fixes, and Effect 4.1.2.
- Many fixes and speedups across the server, terminals, diffs, PR watches, OpenCode, Pi, Cursor, Antigravity and mobile layouts.

## K-code features

- The Oh My Pi logo is the official gradient π.
- The mobile usage panel marks the account pinned to the thread.
- Managed policies can allow or pin the Oh My Pi provider.
- The changelog at kcode.agentbox.io.vn is built from these GitHub release notes, and the download page links to the latest release's assets.

## Fixes

- Adding or reconnecting an environment behind Cloudflare Access no longer fails when the sign-in takes longer than 10 seconds.
- A managed policy that lists `ohmypi` in `allowedDrivers` no longer stops the server.

## Breaking or migration notes

- The server's database moves the Web Push migration after T3 Code's new ones. Existing databases are repaired on first start; no action needed.
- Update the desktop app and the server together: a 0.1.8 app reaching a server over SSH installs the 0.1.8 server runtime from this release.
