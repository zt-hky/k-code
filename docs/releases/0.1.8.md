Fixes a timeout when adding an environment behind Cloudflare Access, and makes the K-code site follow GitHub releases.

## Highlights

- **No more "timed out after 10000ms" behind Cloudflare Access.** The request clock was running while the Access sign-in window was open, so a slow sign-in failed even though the server was fine. The clock now waits for the sign-in and the retry gets its full allowance.

## K-code features

- The changelog at kcode.agentbox.io.vn is now built from these GitHub release notes.
- The download page shows the latest release and links to its real assets.

## Fixes

- Adding or reconnecting an environment behind Cloudflare Access no longer fails when the sign-in takes longer than 10 seconds.

## Breaking or migration notes

- None. Update the desktop app to get the fix; servers need no change.
