First public release of K-code, a community fork of [T3 Code](https://github.com/pingdotgg/t3code).

## Highlights

- New name, brand and installers: desktop apps for Linux, Windows and macOS, plus a headless server and CLI.
- **Oh My Pi** as a first-class provider, with sign-in, thinking levels including `auto`, skills and plan mode.
- **Agent Hub**: a live grid of running subagents, with a per-agent Stop where the provider supports it.

## K-code features

- Agent Hub: no pane cap, responsive columns, a Live/All filter, maximize, and a project-wide running-agents page.
- Batch subagent tasks appear as one entry per task.
- **Full transcript mode** on web, desktop and mobile: a Settings toggle, a chat-header button, a command-palette entry and `mod+alt+shift+e`.
- **Resume native Oh My Pi sessions** with their real titles, across projects. Renames are written back to the session.
- Settings sync across every device connected to the same server.
- One-line installers: `install.sh` and `install.ps1` on kcode.agentbox.io.vn.

## Breaking or migration notes

- This is a fork with its own release channel. Installs of T3 Code are not updated by K-code and the reverse.
