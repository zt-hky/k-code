Oh My Pi grows into a complete provider, and K-code gains loop mode, Tasks and Subagents cards, web push and VS Code in the browser.

## Highlights

- **Oh My Pi** is now sign-in complete: model-provider login, account limits, usage readout and plan mode work without leaving K-code.
- **Loop mode** repeats a message after every turn until you stop it.
- **Tasks and Subagents cards** sit above the composer and show each subagent's model, thinking level and current activity.
- **Web push notifications** tell you when a run finishes while the tab is in the background.

## New (from T3 Code)

- `t3 service protect` keeps the server alive when agents fill memory, and agents yield CPU to the server under pressure.
- Large speedups on idle servers, sidebar and thread loading, git status, checkpoints and run start, with far less memory use.
- Android EAS Simulator sessions for the device panel.

## K-code features

- Oh My Pi: subagents, skills, `/compact`, a clean `/context` view, project suggestions, answering questions in place, steering a live turn, and updating itself from provider settings.
- Usage: Oh My Pi account limits feed the thread readout, group in their own pool, and account emails can stay revealed.
- Open in **VS Code (Web)** beside VS Code, toggleable per device.
- A configurable SSH host for remote editor links, and per-kind ACP instruction toggles.
- Cloudflare Access sign-in on the server (`T3CODE_CLOUDFLARE_ACCESS_*`) and local overlays for the ACP registry.
- Opt-in Vulkan rendering for the server browser (`T3CODE_SERVER_BROWSER_GPU=vulkan`).

## Fixes

- Stop during a restart no longer leaves a thread stuck, and restarts respect a parent's Stop.
- Held queues release agent and scheduled messages once a thread completes a run.
- Completion pushes show the run's latest reply, and image-only messages show the image.
- Installing the `t3` command from the desktop no longer reports its own launcher as another `t3`.
