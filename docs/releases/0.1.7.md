Catches K-code up with T3 Code (about 770 upstream commits) and fixes the two ways a remote environment could not be reached: SSH and Cloudflare Access.

## Highlights

- **SSH environments work again.** Adding an environment over SSH failed with `curl: (22) … 404`. It now downloads the right server archive, and reuses a server that is already running on the host.
- **Cloudflare Access for remote environments (desktop).** Add an environment that sits behind Access and K-code opens the Cloudflare sign-in, remembers it, and asks again when it expires.
- **Side chats**, a single **model and effort** picker, and a **rich text / Markdown** toggle in the composer.

## New (from T3 Code)

- **Side chats** beside the main thread, for questions that should not interrupt a run.
- Pick the model and its effort from **one control**. Threads show when you switch models or effort.
- Switch the composer between **rich text and Markdown source** with a button or `mod+/`.
- **Subagent approvals** appear in the parent thread.
- A **context meter** that fills up and shows tokens against the limit.
- **Pin favorite projects** and archive old ones.
- Review **local commits** one at a time in the Diff pane.
- Scheduled tasks can run **once** at a set date and time.
- **Usage** can be filtered by provider and model.
- Read provider environment variables and Bitbucket or GitCafe credentials from a **secret provider** such as 1Password.
- Copy the app version from General settings.
- **Managed policy** for organization-wide configuration.
- `t3 up` asks how your other devices reach this machine, and `--lan` opens the server to your network.
- Import terminal **Pi** sessions during setup.
- **Antigravity** runtime 1.4.5, with real turn failures and subagent work.
- Pasted text, voice notes, snapshots and files sent without text get their own message shapes. Desktop gains back and forward buttons and swipe navigation.

## K-code features

- Usage follows the account pinned in the thread (Oh My Pi), and keeps it through the next turn.
- Everything from 0.1.6 still works: Oh My Pi, loop mode, Tasks and Subagents cards, Agent Hub, web push and VS Code (Web).

## Fixes

- **SSH environment bootstrap** used upstream asset names that K-code never publishes. The bootstrap, `t3 update` and service install now all read one table, `CLI_RELEASE_ARCHIVES`, which the release workflow also uses.
- **Cloudflare Access**: the desktop detects the Access wall, signs in in its own window, and adds the token to HTTP and WebSocket traffic from the main process. **Settings → Environments** lists these sign-ins with **Sign out**.

## Breaking or migration notes

- Server self-update (`t3 update`) on installs older than 0.1.7 looks for asset names K-code never published, so it cannot find an update. Reinstall once with the installer; later updates work. The desktop app's own updater is unaffected.
- Cloudflare Access sign-in is desktop only. Mobile and app.t3.codes still cannot pass Access; pair them over LAN or Tailscale.
