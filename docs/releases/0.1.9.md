Oh My Pi threads now load the MCP servers you set up in Oh My Pi, and you can manage MCP servers and see skills from K-code.

## Highlights

- **Your Oh My Pi MCP servers load in K-code threads.** Servers from Oh My Pi's user, project, and plugin config were silently skipped before. They now connect alongside K-code's own servers in every new, resumed, or forked thread.
- **Manage MCP servers from Settings → Providers → Oh My Pi → Manage.** Add, remove, enable, disable, test, and authorize servers, and browse their resources and prompts. The **Skills** tab lists what Oh My Pi loads, read-only. Everything runs through Oh My Pi itself.
- **`/mcp` subcommand menu in the composer** on web and mobile. Typing `/mcp ` lists every subcommand; the one you pick is sent to the thread's Oh My Pi session.

## K-code features

- Account switching and the auto-compaction switch for Oh My Pi, added after 0.1.8, are included.

## Fixes

- Oh My Pi no longer ignores the MCP servers configured in Oh My Pi when a thread starts.

## Breaking or migration notes

- None. Changes to MCP servers apply to new sessions; in a running thread, send `/mcp reload`.
