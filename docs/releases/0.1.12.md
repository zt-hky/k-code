Fixes text generation (thread titles, commit messages and other generated text) through OpenAI-compatible gateways such as 9router.

## Highlights

- **Text generation works through 9router.** Thread titles, commit messages and other generated text no longer fail with "returned a reply K-code couldn't read" on OpenAI-compatible gateways that stream by default.

## Fixes

- OpenAI-compatible text generators ask for a non-streamed reply. Gateways such as 9router streamed the reply when the request did not say otherwise.

## Breaking or migration notes

- Still built on T3 Code 0.1.11; this is a K-code patch release.
- Update the desktop app and the server together.
