Fixes text generation (thread titles, commit messages and other generated text) through OpenAI-compatible gateways such as 9router.

## Fixes

- OpenAI-compatible text generators ask for a non-streamed reply. Gateways such as 9router streamed the reply when the request did not say otherwise, and K-code reported "returned a reply K-code couldn't read" for every role.
