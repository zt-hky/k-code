# Web notifications

Choose **Notifications only** or **Notifications with sound** in **Settings → Notifications** and allow notifications when the browser asks. You are alerted when a thread finishes, fails, or needs input or approval. Tap a notification to open its thread.

When you open T3 Code from your own server's address over HTTPS (or `localhost`), the server also sends Web Push notifications, so alerts arrive while the tab is in the background or closed. This covers the environment serving that address; other environments you connect to from the same page alert only while it is open.

On iPhone and iPad (iOS 16.4 or newer), Web Push works only from the Home Screen: open your server's address in Safari, choose **Share → Add to Home Screen**, open T3 Code from the new icon, then turn notifications on. Chrome and other browsers on iOS follow the same rule.

Turning notifications off, or switching to **Sound only**, stops pushes to that device. Signing the device out of the environment stops them too.
